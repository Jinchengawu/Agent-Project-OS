# 隐私与公开仓库卫生

[English](PRIVACY.md)

公开记录必须使用合成身份和相对路径。严禁提交：

- 凭据、token、cookie、私有 endpoint 或环境变量转储；
- 个人绝对路径或用户名；
- 私有公司/项目名称、任务、财务数据或客户数据；
- 完整对话、含私有上下文的提示词、终端全文或无关 diff；
- 生成缓存、本地 Adapter 备份、SQLite 索引或客户端 session 存储。

只保存复现声明所需的最小证据：命令、结果、commit、文件引用、digest 与边界清晰的摘要。私有本地审计可以包含真实拓扑，但必须位于公开仓库之外，也不得成为测试夹具。

CI 会运行保守的路径/密钥/名称扫描。扫描通过不代表可安全发布；任何 push、tag 或包发布前，必须由人工复核 release candidate。
