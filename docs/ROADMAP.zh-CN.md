# 路线图

[English](ROADMAP.md)

## v0.1 — 协议、CLI、Adapters

- 本地优先的项目与 Portfolio 格式。
- Draft 2020-12 Schemas 与离线校验。
- 任务/证据/决策/交接/变更请求生命周期。
- 联邦影响图与可重建 SQLite 投影。
- Codex、Claude Code 正式 Adapter；DeepSeek Harness 预览 Adapter。
- 合成联邦工作区、完整双语文档、发布/隐私门禁。

本版本不建设 Web 产品、团队账号、RBAC、云同步，也不迁移私有项目。

## v0.2 候选

- 稳定的回执创建与契约测试编排命令。
- 上游接口稳定后的 Adapter plugin/package 分发。
- 由策略定义的低风险确定性记录自动接纳。
- 更多导出投影和迁移工具。

## 未来，仅在有证据时

- 只读 Web/桌面控制面投影。
- 基于同一核心协议的 MCP 接口。
- 作为独立产品层的团队/RBAC/云同步。

任何未来视图都必须能从仓库真源重建。早期 Vercel 构想归档在 `docs/future/`，仅作历史上下文，不是当前架构。
