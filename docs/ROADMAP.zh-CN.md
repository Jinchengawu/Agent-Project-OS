## 发布状态

`0.1.0a1` 是已经推送、未打 tag 的历史 Project Kernel 基线。当前本地工作候选为 `0.4.0a1`，不代表已经创建 tag、GitHub Release 或发布包。

| 版本门禁 | 结果 | 当前证据状态 |
|---|---|---|
| `0.1.0a2` | 修正产品边界：Kernel 只是组织操作系统的一层 | 架构与方法文档已完成；README 等待新的 Showcase 批准 |
| `0.2.0a1` | Founder/CEO/PMO/项目 PM 纵向闭环 | 已实现，并有合成集成测试 |
| `0.3.0a1` | Agent HR 注册、评测、版本、晋升、回滚、暂停与退役 | 已实现，并有合成集成测试 |
| `0.4.0a1` | 到期计算、幂等 Cadence、有限重试记录和三端派工渲染 | 已实现；当前本地候选 |
| `0.5.0b1` | 只读大盘、30 项目/50 Agent 规模门禁、两轮私有影子运行 | 大盘与公开规模门禁已完成；尚未运行两轮私有周期，因此 beta 门禁仍开放 |
| `1.0.0` | 冻结 Schema/CLI，验证升级/回滚，并让一个非关键私有项目切到单真源 | 尚未开始；需要独立私有迁移批准 |

## 稳定排除项

V1 不建设团队账号、RBAC、云同步、托管 SaaS 或 Agent Runtime。大盘始终只读且可重建。DeepSeek Harness 在上游契约稳定前保持 Preview。`docs/future/` 下的早期 Vercel 构想只作历史上下文，不是当前架构。
