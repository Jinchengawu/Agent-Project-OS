# Roadmap

[中文](ROADMAP.zh-CN.md)

## v0.1 — protocol, CLI, adapters

- Local-first project and portfolio format.
- Draft 2020-12 Schemas and offline validation.
- Task/evidence/decision/handoff/change-request lifecycle.
- Federated impact graph and rebuildable SQLite projection.
- Codex and Claude Code supported adapters; DeepSeek Harness preview adapter.
- Synthetic federated workspace, bilingual documentation, release/privacy gates.

No Web product, team accounts, RBAC, cloud synchronization, or private-project migration belongs in this release.

## v0.2 candidates

- Stable receipt creation and contract-test orchestration commands.
- Adapter plugin/package distribution after upstream interfaces stabilize.
- Policy-defined automatic acceptance for low-risk deterministic records.
- More export projections and migration tooling.

## Later, only with evidence

- Read-only Web/desktop control-plane projection.
- MCP interface over the same core protocol.
- Team/RBAC/cloud sync as a separate product layer.

Any future view must remain rebuildable from repo truth. The archived early Vercel concept is retained under `docs/future/` as historical context, not as current architecture.
